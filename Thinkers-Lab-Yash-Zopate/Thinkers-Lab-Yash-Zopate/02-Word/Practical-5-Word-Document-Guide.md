# Practical 5 — Professional Documents in Microsoft Word

## Aim
To create and format a professional document using styles, tables, images, headers/footers and references.

## Procedure
1. Open Microsoft Word and create a blank document.
2. Add a title and apply the **Title** style.
3. Add section headings and apply **Heading 1** and **Heading 2** styles.
4. Insert a table using **Insert → Table** and enter sample data.
5. Add a relevant image using **Insert → Pictures**; add alternative text.
6. Add a header containing the document title and a footer with page numbers.
7. Use **References → Table of Contents** to insert an automatic contents list.
8. Add a citation and bibliography using the References tab.
9. Check spelling, page layout and alignment, then save as `.docx` and export a PDF.
