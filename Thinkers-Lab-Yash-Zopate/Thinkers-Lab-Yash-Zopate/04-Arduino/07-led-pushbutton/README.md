# Practical 7 — LED and Push Button

**Components:** Arduino Uno, LED, 220 Ω resistor, push button, breadboard and jumper wires.

**Connections:** LED anode to D9 through resistor; cathode to GND. Push button between D2 and GND. `INPUT_PULLUP` means the input reads LOW when pressed.

**Procedure:** Connect the circuit with power disconnected, upload the sketch, then press and release the button. The LED should turn on only while the button is pressed.

**Result:** LED operation is controlled by the digital push-button input.
